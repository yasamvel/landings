Ключевые возможности

Hermes Agent создан для реальной работы — от автоматизации до исследований

psychology

Замкнутый цикл обучения

Создаёт навыки из опыта, улучшает их при использовании, запоминает вас между сессиями. Становится умнее с каждым днём.

Работает где угодно

VPS за $5, GPU-кластер или serverless (Daytona, Modal). Не привязан к вашему ноутбуку — живёт в облаке.

20+ платформ

Telegram, Discord, Slack, WhatsApp, Signal, Email, SMS, Teams, Matrix и другие — единый gateway для всех мессенджеров.

call_split

Параллельные агенты

Запускайте изолированных саб-агентов для параллельной работы. Один агент пишет код, другой ищет информацию — одновременно.

60+ встроенных инструментов

Веб-поиск, браузер, работа с файлами, терминал, генерация изображений, TTS, MCP-серверы — всё из коробки.

schedule

Планировщик задач

Встроенный cron с доставкой результатов на любую платформу. Утренние дайджесты, мониторинг, бэкапы — всё автоматически.

Персистентная память

Помнит вас между сессиями. Сохраняет предпочтения, факты о проектах, контекст — ничего не теряется.

extension

MCP интеграция

Подключайте любые MCP-серверы для расширения возможностей. Фильтруйте инструменты, управляйте доступом.

record_voice_over

Голосовой режим

Реальное время: CLI, Telegram, Discord, Discord VC. Разговаривайте с агентом как с человеком.

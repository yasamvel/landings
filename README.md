## Структура

- Каждый лендинг — в своей папке
- Статика: HTML/CSS/JS — работает на GitHub Pages из коробки
- Next.js (neporno-site): исходники, требует `npm install && npm run build`

## Синхронизация

- Сервер: `/var/www/weblanding/projects/<name>/`
- GitHub: `yasamvel/landings` (ветка main)
- После создания лендинга — коммит + push

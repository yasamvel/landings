01 Обновление системы apt

Сначала обновляем список пакетов, затем — сами пакеты. Регулярно, желательно раз в неделю.

$sudo apt update
$sudo apt upgrade -y

Обновить и дистрибутив (ядро, базовые пакеты), и очистить лишнее:

$sudo apt dist-upgrade -y
$sudo apt autoremove -y
$sudo apt autoclean

Если обновилось ядро — перезагрузка:

$sudo reboot

02 Установка и настройка fail2ban безопасность

fail2ban автоматически банит IP-адреса после нескольких неудачных попыток входа.

Установка:

$sudo apt install fail2ban -y
$sudo systemctl enable --now fail2ban

Проверка статуса:

$sudo systemctl status fail2ban
$sudo fail2ban-client status

Базовая настройка — создаём локальный конфиг, не трогая дефолтный:

sudo tee /etc/fail2ban/jail.local >> /dev/null <<'EOF'
[DEFAULT]
bantime = 3600          # бан на 1 час
findtime = 600          # окно 10 минут
maxretry = 5            # 5 попыток — и бан

[sshd]
enabled = true
port = ssh
EOF

Применить настройки:

$sudo systemctl restart fail2ban
$sudo fail2ban-client status sshd

03 Закрытие всех портов, кроме 80, 443, 22 UFW

Политика: по умолчанию запрещаем входящие, разрешаем только нужное. Сначала открой SSH, иначе потеряешь доступ к серверу!

$sudo ufw default deny incoming
$sudo ufw default allow outgoing
$sudo ufw allow 22/tcp # SSH — обязательно первым!
$sudo ufw allow 80/tcp # HTTP
$sudo ufw allow 443/tcp # HTTPS
$sudo ufw enable

Проверка:

$sudo ufw status verbose

Ожидаемый результат:

ПортСервисСтатус
22/tcpSSHALLOW
80/tcpHTTPALLOW
443/tcpHTTPSALLOW
остальные—DENY (закрыты)

Если что-то сломалось и доступ потерян — перезагрузить сервер, UFW при старте не активируется, пока не включён ufw enable после открытия нужных портов.

$ echo "Безопасного сервера!"

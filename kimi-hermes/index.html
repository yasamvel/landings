Почему Kimi

Зачем подключать Kimi к Hermes?

Hermes поддерживает кастомных провайдеров. Один ключ — и у агента появляется новая бесплатная модель для повседневных задач.

Полностью бесплатно

Модель moonshotai/kimi-k3-free не требует оплаты. Идеальна для дайджестов, отчётов и рутинных задач агента.

OpenAI-совместимость

Endpoint /v1/chat/completions — Hermes подключается как к обычному OpenAI API. Без SDK и хаков.

120+ моделей в одном ключе

Кроме Kimi — GPT-5.x, Claude, Qwen, DeepSeek, Gemini, Grok. Один ключ на всё.

Инструкция

Подключение за 3 шага

Всё, что нужно — ключ API и правка одного файла конфигурации.

1

Перейди на сайт и зарегистрируйся

Открой сайт tokenrouter.com, создай аккаунт и войди в панель. В разделе API Keys нажми «Create Key» — скопируй ключ. Он начинается с sk-.

Перейти на tokenrouter.com Регистрация бесплатная, карта не нужна 
sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
2

Добавь провайдера в config.yaml

Открой ~/.hermes/config.yaml и добавь блок в custom_providers: 

custom_providers:
  - name: tokenrouter-kimi
    api_key: sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
    api_mode: chat_completions
    base_url: https://api.tokenrouter.com/v1
    model: moonshotai/kimi-k3-free
3

Перезапусти gateway и проверь

Перезапусти gateway, чтобы Hermes подхватил нового провайдера, и проверь ответ: 

hermes gateway restart
curl -s https://api.tokenrouter.com/v1/chat/completions \
  -H "Authorization: Bearer sk-xxx" \
  -H "Content-Type: application/json" \
  -d '{"model":"moonshotai/kimi-k3-free","messages":[{"role":"user","content":"Привет"}]}'
+

Подключи к cron-задачам

В cron-задаче Hermes укажи провайдера custom:tokenrouter-kimi и модель moonshotai/kimi-k3-free — дайджесты и отчёты будут генерировать Kimi. 

hermes cron update <job_id> \
  --model moonshotai/kimi-k3-free \
  --provider custom:tokenrouter-kimi

FAQ

Частые вопросы

Это правда бесплатно?
Да. Модель moonshotai/kimi-k3-free доступна бесплатно через TokenRouter. Достаточно ключа API.
Нужен ли VPN или прокси?
Нет. API доступен напрямую по HTTPS: https://api.tokenrouter.com/v1.
Можно ли использовать для cron-задач?
Да. Укажи provider custom:tokenrouter-kimi в cron-задаче — Kimi будет генерировать дайджесты и отчёты.
Какие ещё модели доступны?
120+: GPT-5.x, Claude Opus/Sonnet/Haiku, DeepSeek, Qwen, Gemini, Grok, GLM, MiniMax, Mistral. Полный список — GET /v1/models.
Что такое TokenRouter?
Бесплатный API-роутер, который агрегирует десятки LLM-провайдеров за одним ключом и одним OpenAI-совместимым endpoint.

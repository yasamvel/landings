# Проект: neporno.site

Создай современный одностраничный лендинг для юмористического сайта neporno.site.

## Технологии
- Next.js (App Router)
- React
- TypeScript
- TailwindCSS
- Framer Motion
- Lucide Icons
- shadcn/ui
- Responsive design
- Dark mode by default

## Стиль
Вдохновение: Apple, Stripe, Vercel, Linear, Framer + немного эстетики сайтов начала 2000-х для взрослых:
- тёмный фон
- неоновый розовый
- пурпурный
- фиолетовый
- мягкое свечение
- стеклянные панели (blur)
- большие заголовки
Всё выглядит современно и дорого.

## Цветовая схема
- Background: #050505
- Accent: #ff0080
- Secondary: #9c27ff
- Text: #ffffff
- Cards: rgba(255,255,255,0.05)

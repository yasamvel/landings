Компоненты
◈

3x-ui панель

Веб-интерфейс управления с поддержкой всех современных протоколов. VLESS, Trojan, WebSocket, gRPC.

◈

nginx + SSL

Обратный прокси с SNI-роутингом. Let's Encrypt с автообновлением. HTTP/2, HTTP/3.

◈

Clash-подписка

Один URL — разный ответ. Clash получает clash.yaml, браузер — стандартную страницу.

◈

VLESS+REALITY

Маскировка под реальный сайт. Домен назначения настраивается, трафик неотличим от HTTPS.

◈

Диагностика сети

MTR-трейс до вашего IP, тест скорости (512 МБ), всё в браузере по ссылке.

◈

Бэкап и restore

Полный бэкап: конфиги, БД, бинарник, SSL, systemd, cron, UFW. Восстановление на чистом сервере.

Установка
# Шаг 1 — скачать скрипт
$ wget -qO x-ui-latest.sh https://raw.githubusercontent.com/mozaroc/3x-ui-pro/main/x-ui-latest.sh
[################################################################] 100%
 
# Шаг 2 — запустить
$ bash x-ui-latest.sh -install y \
-subdomain panel.example.com \
-reality_domain r.example.com
 
# Или с автоопределением домена:
$ bash x-ui-latest.sh -install y -auto_domain y
 
$ tail -f /var/log/3x-ui-install.log
Параметры
# x-ui-latest.sh — флаги запуска
Флаг Значение Описание
-install y / n Запустить установку
-subdomain домен Домен панели и подписок
-reality_domain домен Домен назначения для REALITY
-auto_domain y / n Авто-определение домена
-uninstall y Полное удаление
# Удаление:
$ bash x-ui-latest.sh -uninstall y
